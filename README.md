# Hungry Porker Game
Feed Porker and watch him get bigger until... POP!

Hungry Porker is a fanmade and cute parody of Pop the Pig by Goliath and the food list isn't just burgers.

> [!NOTE]
> Hungry Porker is not a real board game and is not created by Goliath, it was created by Jerrybomb's Goliath Vids and Lucas Berry's Vids.
> This game was (not actually) owned by Cartoon Kid Toys.

> [!WARNING]
> Hungry Porker can contain a jumpscare where he "pops" that scared a couple of people.

# What is Pop the Pig?
Pop the Pig is the real version of Hungry Porker by Goliath.
